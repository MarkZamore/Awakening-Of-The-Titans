# Состояние проверок Awakening Of The Titans

Дата: 4 ноября 2026 года. Основа: Awakening Of The Titans 1.8.1, CurseForge project `1535260` / file `9427704`, Minecraft 1.21.1 / Fabric 0.19.5 / Java 21. Live публичный API CurseForge на дату проверки по-прежнему ставит 1.8.1 первым файлом; дата публикации 3 ноября, 21:47 UTC. Поисковый кеш страницы Files отстаёт от API.

## Проверенные входы

Архив автора: 78,417,346 байт, SHA256 `a6343f7272933f332ecd7436c83ca200b3d49cf59b69898858d2c3c1dac74989`. Исторический upstream сохраняет все115 manifest entries и457 overrides. Его JAR/конфиги/ресурсы не подменены производными файлами. Сохранены Danny’s AOT и пять аддонов, Burnt и You’re in Grave Danger; второго мода могил нет.

Итоговые игровые входы:579 файлов,110 JAR,9 операций overlay. Helper1.0.2:36,159 байт, SHA256 `af418ee72bf91f46af654d34cc3f4e7a3d0dc723c178aaceaf1daa2339117f02`; полный inventory SHA256 `7bb81fe7df8563b921a1ff978d9b1ce261df803a3ede972f9a5f4b5d23d5db02`. Образ финального клиента `final-06` зарегистрировал253 Fabric records. После исключения Minecraft/Java/Fabric Loader и управляемого транспорта e4steam библиотека содержит249 фактических mod ID. Все110 исходных JAR побайтно совпали со снимком и экземпляром работающего клиента; `library/loaded-mods.json` снят с реального клиента, не исправлен по догадке.

Author JAR не заменялись. Helper меняет BASE runtime в двух компонентах: безопасное fallback-возрождение GlobalSpawn и каталоги native/browser cache MCEF. Точные SHA, caller/site, guards и последствия раскрыты в SAFETY.md и tools/world-type-lock/README.md. Файлы авторских модов и их конфиги остаются прежними; это не утверждение о неизменном runtime-поведении.

## Оставшиеся ERROR и ограничения

Baseline полного клиента:208 `No data fixer registered for <entity ID>` и два offline-QA ERROR получения user properties/Realms. В `final-06` ровно212 ERROR:те же208 data-fixer ID, два baseline auth/Realms и два `Steam runtime failed` из SteamAPI_Init. Steam не авторизован в лабораторном процессе; сообщение требует запущенного Steam с входом и одинаковым уровнем привилегий. FATAL0, нормальный exit0. Финальный dedicated имеет208 ERROR data fixer, других ERROR0.

Отдельный финальный wearable-harness клиент `fixed-06` завершился с exit0/FATAL0 и215 ERROR:208 data fixer, два baseline auth/Realms, два Steam runtime, один Steam LAN share и два profile-key HTTP401 при offline QA publish. Это другое временное окно; оно не смешивается с212 ERROR клиента `final-06`. Новых неизвестных content/Mixin/CEF ERROR в нём нет.

В отдельной ранней integrated session были также `Could not start the Steam LAN share` и HTTP401 `/player/certificates` для offline сессий. Они не объявлены унаследованными только потому, что клиент продолжил работу. При одновременном shutdown двух TCP-клиентов один раз появился новый `Negative index in crash report handler (13/21)` рядом с Connection reset; оба exit0. Причина окончательно не установлена, это не baseline PASS. Повторный последовательный shutdown финального клиента этой ошибки не дал. Ранний `GL_INVALID_ENUM` встречался в baseline и раннем derived запуске; происхождение не установлено и не маскировалось отключением эффектов.

Реальные Steam friendship/discovery/P2P и визуальная оценка двух клиентов не выполнены. Computer Use был остановлен пользователем Esc; последующие проверки программные, без физического ввода/обходных снимков. Native provider fixture, TCP, метаданные и dedicated Done не подменяют эти ограничения. Непроверенные claim gates, способности всех аддонов, все виды смерти/инвентаря и все формы титанов не объявлены PASS.

Личные игровые экземпляры и миры не изменялись; все save/copy действия относятся к независимым одноразовым QA fixtures. Приватные paths/PNG/registry/raw logs не публикуются. Подробные воспроизводимые инструменты находятся в tools/runtime-qa и tools/identity-compat, Safety scope — в SAFETY.md.
