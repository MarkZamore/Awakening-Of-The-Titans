# Управление Awakening Of The Titans

По решению пользователя от 7 ноября 2026 года пресет точно воспроизводит все 239 назначений из авторского options.txt Awakening 1.8.1, CurseForge project 1535260, file 9427704. Авторские совпадения клавиш сохраняются. Отдельных переназначений LANMinecraft в этой раскладке нет.

Точный авторский файл закреплён SHA256 в tools/upstream-lock.json. В layout.json записаны этот хеш и SHA256 отсортированных строк клавиш. registered-keys.json содержит те же назначения, ранее записанные настоящим Minecraft 1.21.1 с Fabric 0.19.5. Генератор отклоняет переопределения, изменённый авторский хеш и расхождение снимка клавиш.

Например, B снова совмещает авторские превращение и рюкзак, Space используется для прыжка и выхода из титана Stronger Shifters. Пересечения сохранены как часть запрошенной авторской раскладки. Перечень общих физических клавиш находится в layout.json.

Пресет применяется существующей кнопкой лаунчера после подтверждения игрока. Применение заменяет строки клавиш в личном options.txt. Файл configureddefaults/options.txt содержит только тот же авторский выбор ресурспаков, что YOSBR, для первого применения при отсутствии личного файла.

Проверки из корня сборки:

    python -B tools/keybinds/build_preset.py --check
    python -B tools/keybinds/check_preset.py
    python -B tools/keybinds/check_preset.py --author-options <точный-авторский-options.txt>

При обновлении авторской основы извлеките её options.txt из проверенного архива, повторно сопоставьте реальные зарегистрированные назначения и обновите их снимок и хеши. Изменение JAR также требует обновления native-снимка. После пересборки пресета обновите его overlay-пин и distribution-lock штатным pipeline. Проверка должна подтвердить равенство всех авторских назначений.

Предыдущие игровые QA от 6 ноября относились к прежнему пресету с 32 переназначениями и не являются новым игровым прогоном этой версии. Для текущего изменения проверяются точное равенство авторским назначениям и целостность поставки. Новый запуск клиента, dedicated server и Steam при этой замене не выполнялись.
