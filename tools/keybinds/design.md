# Управление Awakening Of The Titans

Раскладка сохраняет WASD, Shift, Ctrl, мышь, клавиши панели 1–9 и авторские боковые кнопки ODM. Среди изменений `I` открывает рюкзак, `F7` открывает квесты, `Home` открывает метки Xaero, `]` открывает навыки ODM, `End` выделен выходу из титана Stronger Shifters. Основное превращение Danny остаётся на `B`, альтернативное превращение Stronger Shifters использует правый Alt. Перезарядка клинка остаётся на `R`, APG и огнестрельного оружия используют запятую и точку. Для части действий самолётов, телег и редких переключателей выделен цифровой блок. На клавиатуре без цифрового блока эти назначения можно заменить в игровом меню.

`registered-keys.json` хранит строки, записанные самим Minecraft 1.21.1 с Fabric 0.19.5 и Java 21. Независимый клиент получил только авторские строки клавиш из проверенного `options.txt` Awakening 1.8.1. После загрузки ресурсов штатный `GameOptions.write` записал все 239 назначений. SHA256 Minecraft и каждого активного JAR привязывают этот снимок к составу.

`layout.json` задаёт изменения и разрешённые группы общей физической клавиши. Контексты сверены по классам закреплённых JAR. `DannysAotClient` опрашивает клавиши способностей в режимах титана и Founder, а `FounderHotbarKeyMixin` подавляет переключение панели в своём Founder-сценарии. Номера остаются общими с обычной панелью, поэтому проверка не обещает подавление панели для каждой формы. `KeyBindings` и `KeyboardHandlerMixin` Immersive Aircraft обслуживают управление транспортом. `WallJump`, `BreakfallReady`, `FastRun` и `ClingToCliff` ParCool оставляют авторские жесты для соответствующего состояния движения. JEI различает экран, область под курсором и действия интерфейса в `InternalKeyMappings`. Физические совпадения этих клавиш сохранены осознанно.

Выпуск добавляет в overlay `launcher/controls-preset.txt` и `configureddefaults/options.txt`. Второй путь использует тот же исходный шаблон из двух авторских списков ресурспаков, что и YOSBR. Он нужен существующей кнопке лаунчера, если при применении после полной установки ещё нет личного `options.txt`. В существующем файле подтверждённое применение меняет строки клавиш. Если старая установка получила только свежие файлы `launcher/` и её личный `options.txt` отсутствует, сначала запустите игру с полной синхронизацией, чтобы она получила шаблон.

В QA 6 ноября 2026 года служба лаунчера изменила 32 назначения и сохранила все 107 остальных строк Options. Повторное применение дало 0 изменений. С отдельным пустым профилем первое применение записало 239 клавиш и оба авторских списка ресурспаков. После повторного запуска игра записала все 239 значений пресета без расхождений. Изолированный клиент вошёл в новый мир `dannys-aot:paradis`, встроенный сервер сохранил все измерения, процесс завершился с кодом 0. В журнале осталось 208 сообщений data fixer, по одному offline user properties и Realms. Это известные семейства baseline. Физические нажатия всех действий, dedicated и Steam в этой проверке не выполнялись.

При изменении состава сначала восстановите и проверьте точные JAR, затем в независимом клиенте откройте экран управления и завершите его штатной кнопкой или вызовите запись Options в QA после завершения загрузки ресурсов. Импортируйте сохранённый файл и пересмотрите изменения и контексты.

```powershell
python -B tools/keybinds/build_preset.py --capture <QA-options.txt>
python -B tools/keybinds/build_preset.py --check
```

После изменения пресета обновите его размер и SHA256 в `tools/overlay.json`, выполните `prepare_pack.py` и `check_preset.py`. При снятии предложения удалите обе операции overlay и обновите distribution lock штатной подготовкой. Полные настройки игрока, игровые миры и QA-клиент в поставку не входят.
