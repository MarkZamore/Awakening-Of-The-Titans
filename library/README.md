# Происхождение библиотеки

`content.json` содержит имя Awakening Of The Titans, описание фактического состава и проверенные отношения аддонов. Фактически выбранные ID и версии берутся из exact-hash `loaded-mods.json` полного клиента; имена сопоставлены с выбранной версией метаданных JAR. Объявленный, но не выбранный вариант вложенной зависимости не попадает в список; версии не исправляются по догадке из имени файла. `mod-pages.json` связывает каждый активный mod ID с официальной страницей проекта. Неполное покрытие останавливает генерацию.

Поле `content.json:name` — единственный редактируемый источник видимого имени. Все сгенерированные подписи получают его через общий механизм; `relativePath` и `id` остаются стабильными идентификаторами установки, не дополнительными переключателями имени.

## Основные страницы и отношения

Пять аддонов относятся к `dannys-aot`: `daotoc` — OverlyConfigured, `los_gear` — Final Season Gear, `atakanshift` — Stronger Shifters, `eldian_npcs` — Eldians, `aot_camera_roll` — Fliping. Основание — авторский `modlist.html` архива Awakening 1.8.1 и страницы именно этих аддонов, а не одни только зависимости Java. Civilian Aviation относится к Immersive Aircraft, ExtraQuests — к FTB Quests, Sodium Extras и Reese’s Sodium Options — к Sodium. Вспомогательные API, внутренние модули и Java-библиотеки вынесены в технический раздел; самостоятельные оптимизации остаются в основном списке.

Для верхнеуровневых файлов основной источник — точные project ID/file ID и HTTPS-страницы из авторских `manifest.json`/`modlist.html`, сопоставленные с реальными файлами в `tools/upstream-lock.json`. Поэтому Fabric-порты ParCool, Sophisticated Backpacks/Core и NoisiumForked открывают страницы конкретных портов. Поле `homepage` в JAR не заменяет проверенное происхождение: оно может вести к оригиналу другого загрузчика или к шаблонному проекту.

Часть авторских внутренних версий отличается от названия релиза: Danny’s AOT скачан как 2.5.2, но объявляет 2.4.1; Final Season Gear 1.2.1 объявляет 1.0.0-r316; Stronger Shifters 1.3.0 объявляет 1.0.0; Fliping 1.0.2 объявляет 1.4.4. Это не результат подмены файлов: lock фиксирует точные исходные SHA256. В библиотечном списке показаны версии, реально выбранные Fabric Loader, включая разрешение дубликатов вложенных зависимостей.

## Снимок реально загруженного состава

Снимок `loaded-mods.json` снят в полном production-profile клиенте `final-06` с helper 1.0.2, 4 ноября 2026 года. Все 110 JAR совпали по SHA256 с исходной поставкой; Fabric зарегистрировал 253 записи. Три платформенные записи `minecraft`, `java`, `fabricloader` и управляемый лаунчером транспорт `e4steam`, не входящий в исходные JAR сборки, исключены из её счётчика. Библиотека показывает 249 реально загруженных модов, включая технические библиотеки и YOSBR.

Fabric выбрал, в частности, Night Config 3.8.0, iCommonLib 107+1.21.1, MixinExtras 0.5.5, MixinSquared 0.3.7-beta.2 и TRansition 1.0.27. Наивное чтение первого встретившегося nested JAR давало другие версии; этот вариант подсчёта не используется. Снимок отклоняется после изменения любого исходного JAR или платформы и должен быть снят повторно.

Объявленные внутри JAR `c2me-opts-natives-math` и `com_github_llamalad7_mixinextras` этим клиентом не выбраны. Они удалены из активных `mod-pages.json`/`libraryIds`, их историческое происхождение сохраняется здесь: внутренний модуль [C2ME](https://www.curseforge.com/minecraft/mc-mods/c2me) и упакованная копия [MixinExtras](https://github.com/LlamaLad7/MixinExtras). Физические авторские JAR при этом не изменялись.

## Вложенные компоненты и исключения

- Все `fabric-*` модули Fabric API открывают официальный проект Fabric API; отдельными независимыми модами с собственными страницами они не являются. `fabric-permissions-api-v0` имеет собственный проект и открывает его на Modrinth.
- Внутренние `c2me-*` модули открывают C2ME; `icommon` и `icommon-api-configuration` — iCommonLib, несмотря на шаблонные Fabric Example контакты внутри bundle. Каждый `porting_lib_*` открывает официальный общий Porting Lib. Эти модули поставлены внутри закреплённых JAR, отдельно не добавлялись.
- У XaeroLib, Kirin, LibGui и Dungeon Config существуют официальные страницы CurseForge; они используются и для встроенных вариантов. Для Apollib используется доступная, хотя и unlisted, страница автора на Modrinth.
- Математические, сериализационные и другие Java-зависимости открывают их собственные авторские репозитории: Kotlin/KotlinX, Night Config, Caffeine, asyncutil, RxJava, Reactive Streams, JCTools, ANTLR, GLSL Transformer, JCPP, TwelveMonkeys, Quilt JSON5, Javassist, MochaFloats, LibNinePatch, Jankson и остальные. Это исходники именно библиотек, не одноимённых Minecraft-модов. Snakeyaml открывает основной Codeberg-репозиторий, а не GitHub-зеркало.
- `com_teamresourceful_yabn` — встроенная Java-библиотека Resourceful Lib. Отдельный доступный официальный проект с загрузками не подтверждён; ссылка ведёт на официальный Resourceful Lib, содержащий закреплённый компонент. Это явно ограниченное исключение, не страница другого мода. О происхождении YABN также сообщает [сам Team Resourceful](https://teamresourceful.com/blog/development-update).
- `cloth-basic-math` открывает исходники Cloth Config; `voicechat_api` — официальный Simple Voice Chat. Встроенные API не требуют отдельной установки.
- ChunkDebug находится в авторских overrides и имеет страницу автора на Modrinth. Keybind Fix из overrides открывает собственную CurseForge-страницу.
- `aot_world_type_lock` — собственный компонент этой производной сборки, отдельного проекта CurseForge/Modrinth у него нет. Его официальным источником является [репозиторий Awakening Of The Titans](https://github.com/MarkZamore/Awakening-Of-The-Titans), исходники находятся в `tools/world-type-lock`.
- `yosbr` — дополнительно закреплённая NEW техническая зависимость [YOSBR автора shedaniel](https://www.curseforge.com/minecraft/mc-mods/yosbr), CF 374274/4581910. Она восстанавливает только отсутствующий options.txt из двух авторских списков ресурспаков и сохраняет все существующие личные настройки. Проверка и exact-SHA находятся в `tools/first-launch-defaults`.

Stronger Shifters, project `1653965`, file `8711093`: публичный file API на момент подготовки возвращал `data:null`, но закреплённый авторским архивом файл был доступен на официальном CDN. Исключение восстановления привязано к точному пути, размеру и SHA256, не разрешает произвольную замену. Страница проекта доступна и используется как ссылка названия; шаблонные `authors/homepage` этого JAR не считаются подтверждением происхождения.

## Обновление

При добавлении/замене JAR повторить сопоставление ID, файла, автора, форка и страницы. Для нового mod ID обязательна новая проверенная ссылка; поисковая выдача, зеркало, direct JAR и страница жалоб не подходят. Если прежде подтверждённый авторский адрес недоступен, сохранить `{ "url": "https://…", "available": false }`: название должно стать обычным текстом до восстановления адреса. Онлайн-поиск выполняется при подготовке, не в лаунчере и не при открытии названия мода.
